STEP 03 · MEMBERSHIP IS NOT A COPILOT LICENSE

가입했어도 Copilot은 별도 권한입니다. 직접 확인하세요.

  1. 운영자가 같은 GitHub 사용자명에 조직 Copilot 권한을 배정했는지 확인합니다. 배정은 운영자가 하는 일입니다.
  2. 같은 계정에서 Settings → Copilot을 열고 새로고침하거나 다시 로그인합니다.
  3. Copilot Free만 보이거나 개인 결제를 요구하면 직접 유료 가입하지 말고 사용자명과 화면 상태만 운영자에게 전달합니다.
좌석

조직에 가입했지만 Copilot 권한이 없을 때

  1. 가입한 정확한 조직과 내 사용자명을 확인합니다.
  2. Copilot 설정에 Ask admin for access 버튼이 보이면 눌러 신청합니다. 보이지 않으면 승인된 문의 경로로 운영자에게 요청합니다.
  3. 운영자가 승인·배정한 뒤 새로고침하거나 다시 로그인합니다.

구분: 이 신청은 Copilot 사용 권한 요청입니다. 조직 가입 요청과 다르며, 신청만으로 Copilot이 켜지지 않습니다.

개인 Copilot 유료 플랜(Pro·Pro+·Max)을 쓰고 있다면: 조직 좌석을 받는 순간 개인 플랜이 자동 취소되고 일할 환불될 수 있습니다. 유지해야 한다면 가입 전에 운영자와 상의하세요. 단순 조직 가입은 영향이 없고 좌석 배정이 기준입니다. 공식 라이선스 기준 ↗
채팅이 된다고 조직 권한이 확인된 것은 아닙니다. 개인 Free/Pro로도 답할 수 있으므로 운영자의 좌석 배정과 따로 확인하세요.

STEP 04 · CHOOSE YOUR WORKSHOP ENVIRONMENT

질문만 하면 브라우저, 코드를 만지면 개발 환경을 엽니다.

설명·오류 이해 질문만 한다면 05 질문 실행으로 바로 이동하세요. 코드를 수정·실행하는 실습이면 운영자가 준 실습 저장소를 열고 아래 한 가지를 선택합니다. 저장소·브랜치·실행 방법은 README에서 확인합니다.

Codespaces · 설치를 줄이고 싶을 때

브라우저의 VS Code로 시작

  1. 실습 저장소에서 Code → Codespaces → 새 Codespace를 엽니다. 안내된 브랜치·머신 유형을 사용합니다.
  2. 비용 부담 주체·한도가 운영자 안내와 맞는지 확인합니다. 개인 카드 등록·예산 변경을 요구하면 멈추고 운영자에게 확인합니다.
  3. 준비되면 저장소 파일·README가 보이는지, Copilot 상태와 Accounts의 사용자명이 내 계정인지 확인합니다.
  4. README의 설치·실행 명령을 따릅니다. 웹 앱은 Ports → Open in Browser로 확인하고, 승인 없이 포트를 공개하지 않습니다.

공식 Codespaces 시작 ↗

VS Code · 내 PC에서 작업할 때

배정 저장소와 같은 계정으로 로그인

  1. 공식 VS Code와 README의 개발 도구를 준비하고, 승인된 실습 저장소를 clone해 폴더를 엽니다.
  2. 상태 표시줄의 Copilot 아이콘(Use AI Features) 또는 Sign in to use Copilot으로 조직 Copilot 권한을 받은 개인 계정에 로그인합니다.
  3. 브라우저와 IDE의 사용자명이 같은지 확인합니다. 계정이 여러 개면 Accounts → Manage Extension Account Preferences → GitHub Copilot Chat에서 이 작업 공간의 계정을 고릅니다.
  4. README의 실행 방법을 확인하고 저장소 질문을 실행합니다. 창이 열렸다고 Copilot 준비가 끝난 것은 아닙니다.

STEP 05 · VERIFY A RESPONSE IN YOUR CHOSEN ENVIRONMENT

Copilot을 열고 질문 1개를 실행하세요.

브라우저 GitHub Copilot 열기 ↗

  1. 조직에 가입한 같은 개인 GitHub 계정으로 로그인했는지 확인합니다.
  2. 아래 질문을 복사해 입력하고 Enter를 누릅니다. 답변이 오면 질문·오류 이해·지시문 작성에 쓸 준비가 된 것입니다.
  3. 답변은 공식 문서와 실습 배정표로 확인합니다. Copilot의 제안만 보고 권한·모델·TPM을 임의로 바꾸지 않습니다.

2. Copilot 답변 표시 확인

질문과 답변이 같은 대화에 표시되면 사용 테스트는 끝입니다. 답변의 정확성과 조직 좌석 배정은 따로 확인합니다.

코드 실습이면 · 같은 저장소를 이해하는지 추가 확인

Codespaces 또는 VS Code에서 실습 저장소의 README를 열고 Copilot Chat에 아래 질문을 입력합니다. 답변의 경로·실행 방법을 실제 파일과 대조하세요. 웹 채팅의 일반 답변만으로는 IDE의 로그인·저장소 접근이 확인되지 않습니다.

이후의 코드 변경·명령은 실습 지시에 따라 검토한 뒤 진행합니다. 개인 토큰·Azure 키·고객 실데이터를 채팅에 넣지 않습니다.

Foundry와 Copilot의 한도는 별개입니다. Foundry의 gpt-6.1-terra TPM 배분은 모델 배포용이며 Copilot 좌석·사용 한도와 공유되지 않습니다. Copilot 모델은 조직이 허용한 목록과 실습 안내를 따릅니다.
공개·합성 데이터만 사용하세요. 고객 실데이터·비공개 코드·암호·MFA 코드·API 키·연결 문자열을 질문에 넣지 않습니다. 오류 화면은 민감 정보를 가린 뒤 승인된 지원 경로로만 전달합니다.

STEP 06 · SAVE BEFORE THE TEMPORARY ENVIRONMENT ENDS

마무리: 산출물을 보존하고, 일정을 확인합니다.

  1. 남길 변경은 운영자가 허용한 브랜치에 commit·push하고 실제 저장소에서 확인합니다. 임시 조직 밖에 보존해야 하면 승인된 비공개 위치를 쓰고, 코드·고객 자료를 임의로 공개하지 않습니다.
  2. 사용한 Codespace는 Stop합니다. 브라우저 탭을 닫아도 유휴 제한(기본 30분)까지 실행되며, 정지 후에도 저장 공간 비용이 남을 수 있습니다.
  3. 좌석·조직·저장소·Codespaces의 삭제와 보존은 운영자 정책을 따릅니다. 임시 조직 삭제는 내 개인 GitHub 계정 삭제와 다릅니다.
기간뜻주의
자가가입 링크의 시작·만료초대를 요청할 수 있는 시간행사일·조직 삭제일과 같지 않습니다. 만료되면 운영자에게 새 안내를 받습니다.
발송된 GitHub 초대내가 수락할 수 있는 시간미수락 초대는 7일 후 만료됩니다. 링크가 유효해도 별도 수락이 필요합니다.
임시 조직 삭제 예정일저장소·행사 콘텐츠가 정리되는 날이 날짜 전에 필요한 산출물을 보존합니다.

신청했지만 초대가 없음이메일(스팸함 포함)과 조직 URL을 확인합니다. 자가가입은 사이트의 요청 상태도 확인하세요. 그래도 없으면 사용자명과 진행 경로를 운영자에게 전달합니다. 요청만으로는 멤버가 아닙니다.
자가가입 링크가 열리지 않음·기간 오류운영자가 준 최신 링크·시작/만료 시각·시간대를 확인합니다. URL을 고치거나 공개 채널에 올리지 않습니다.
요청은 성공했는데 조직이 안 보임요청과 멤버십은 다릅니다. 같은 GitHub 계정으로 이메일의 초대를 수락합니다.
초대가 만료됨·수락이 안 됨초대는 7일 후 만료됩니다. 초대받은 이메일이 내 계정의 인증된 이메일인지 확인하고, 안 되면 운영자에게 사용자명으로 재초대를 요청합니다.
2FA·SSO 때문에 가입 안 됨GitHub 2FA를 먼저 설정하고 운영자가 안내한 SSO 절차를 따릅니다. 인증 코드를 공유하거나 정책을 우회하지 않습니다.
가입했는데 Copilot이 없음새로고침·재로그인 후 Settings → Copilot을 봅니다. Free만 보이거나 결제를 요구하면 직접 가입하지 말고 사용자명과 화면 상태를 운영자에게 전달합니다.
브라우저 Copilot이 열리지 않음운영자에게 조직 정책과 실습에 허용된 모델·사용 한도를 확인해 달라고 요청합니다.
브라우저는 되는데 IDE에서 Copilot이 안 됨VS Code/Codespaces의 로그인 사용자명과 Manage Extension Account Preferences → GitHub Copilot Chat의 계정이 조직 권한을 받은 계정인지 확인합니다. 개인 Free 계정 로그인을 조직 권한으로 착각하지 않습니다.
Codespaces 없음·저장소 접근 불가·결제 요구개인 카드 등록이나 공개 저장소 복제로 우회하지 않습니다. 사용자명·저장소·화면을 운영자에게 전달합니다.
개인 Copilot 구독이 바뀜조직 좌석을 받으면 개인 Pro·Pro+·Max가 자동 취소·일할 환불될 수 있습니다. Settings → Copilot과 공식 안내로 확인하고 운영자와 상의합니다. 좌석을 제거하면 개인 플랜이 복구된다고 가정하지 않습니다.

문의에는 GitHub 사용자명·대상 조직·진행 경로(초대 수락 / 자가가입)·선택 환경·발생 시각·민감 정보를 가린 화면만 포함합니다. 암호·2FA 코드·토큰·서명된 링크는 보내지 않습니다.

기준일 2026.11.09 · 메뉴 이름과 정책은 GitHub 업데이트로 바뀔 수 있습니다. 이 페이지는 가입·구매·권한 부여를 실행하지 않으며, 실제 링크·저장소·종료일은 운영자 안내를 따릅니다. 운영자는 GitHub 운영자 가이드를 참조하세요.
