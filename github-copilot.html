STEP 02 · MEMBERSHIP IS NOT A COPILOT LICENSE

운영자가 배정한 Copilot 사용 권한을 확인합니다.

  1. 조직 가입을 마친 같은 GitHub 사용자명에 Copilot Business/Enterprise 좌석이 배정되었는지 운영자에게 확인합니다. 좌석 배정은 관리자 작업입니다.
  2. 같은 계정에서 Settings → Copilot을 엽니다. 조직 제공 권한이 불명확하면 운영자가 Copilot → Access의 실제 좌석 목록에서 같은 사용자명을 대조합니다. 개인 Billing & licensing의 Free/Pro 표시만으로 조직 좌석 배정을 판단하지 않습니다.
  3. 배정 후 페이지를 새로고침하거나 재로그인합니다. Copilot Free만 보이거나 개인 결제를 요구하면 직접 유료 가입하지 말고 운영자에게 사용자명과 화면의 상태만 전달합니다.
좌석

조직에 가입했지만 Copilot 좌석이 없을 때

  1. 이미 가입한 정확한 조직과 본인 사용자명을 확인합니다.
  2. 실제 Copilot 설정에 Ask admin for access 버튼이 표시되면 신청합니다. 표시되지 않으면 승인된 문의 경로로 운영자에게 요청합니다.
  3. 관리자가 요청을 승인하고 실제 좌석을 배정한 뒤 새로고침·재로그인합니다.

구분: 이 요청은 Copilot 사용 권한 신청입니다. 앞의 B 조직 가입 신청과 다르며, 요청 제출만으로 Copilot이 활성화되지 않습니다.

채팅이 된다는 것만으로 조직 좌석이 확인되지는 않습니다. 개인 Free/Pro로도 응답할 수 있으므로 조직 멤버십과 운영자의 좌석 배정을 따로 확인합니다.

관리자만 아래 화면을 참고합니다. 참가자는 위 A / B → 좌석 확인 → 질문 실행까지만 진행하세요.

관리자용 공식 화면 · People 초대 / Copilot Access 좌석 배정

1. 조직 멤버 초대

People → Invite member → 참가자 사용자명 입력 후 Invite → Role in the organization: Member → Send invitation.

2. Copilot 좌석 별도 배정

Settings → Copilot → Access → Purchase for selected members → Users and teams → 참가자 선택 → 구매 확인.

  1. 대상·접수: 일반 GitHub 조직 기준입니다. Enterprise Managed Users는 SCIM 절차를 사용합니다. A는 먼저 초대, B는 신청·참가 여부 확인 후 승인·초대합니다. 공개 이슈·사이트에 고객 명단을 모으지 않습니다.
  2. 권한·라이선스: 멤버 기본 저장소 접근·팀과 초대 한도·조직 멤버 라이선스를 확인합니다. 고객에게 Owner나 불필요한 접근을 주지 않고 본인 수락을 확인합니다.
  3. 좌석: 승인된 Copilot Business/Enterprise 환경에서 필요 시 Allow this organization to assign seats → Start adding seats → Purchase for selected members → 참가자 선택 → Continue to purchase → Purchase seats. 실제 할당 목록을 확인합니다.
  4. 정책·리허설: Copilot → Policies의 Copilot in the cloud(이전 이름 Copilot in GitHub.com)와 상위 엔터프라이즈 정책을 확인합니다. 테스트 참가자의 가입·좌석·브라우저 응답을 인계 전에 검증합니다.
  5. 비용·종료: 좌석은 배정 시점부터 과금되며 남은 청구 주기만큼 일할 계산됩니다. 좌석을 회수해도 현재 청구 주기 말까지 과금이 이어지고 사용자의 접근도 그때까지 유지될 수 있습니다(조직에서 제거·정지한 사용자는 접근만 즉시 중단되고 좌석 과금은 주기 말까지 이어짐). 승인된 참가자만 배정하고 종료 후 승인된 정책대로 좌석·임시 멤버십을 회수합니다. 개인 Copilot Pro·Pro+·Max 플랜 보유자는 조직 좌석을 받으면 개인 플랜이 자동 취소됩니다. 5시간 자동 종료가 아니며 개인 GitHub 계정은 삭제하지 않습니다.
