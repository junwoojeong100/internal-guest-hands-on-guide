GitHub Copilot

GitHub Copilot 핸즈온 지원 안내

각 고객사 주관 해커톤 및 핸즈온 워크샵을 진행하시면, 최소 10명, 최대 50명 참여하시는 분들에 대해서 1인당 $100의 AI Credit을 드립니다

행사 전용 GitHub 조직에서 GitHub Copilot을 바로 사용하실 수 있어요.

참여자 분들의 GitHub username 또는 GitHub에 등록된 이메일 계정 리스트를 본 메일에 회신해 주세요

GitHub username

예: octocat, monalisa

또는

GitHub에 등록된 이메일 계정

예: kim@example.com, lee@example.com

개인 GitHub 계정만 사용할 수 있어요. 회사 관리 계정(EMU, 사용자명에 _ 포함)은 사용할 수 없습니다. 계정이 없다면 github.com/signup에서 무료로 만들 수 있어요.

이후에는 이렇게 진행돼요

  1. 행사 약 7일 전

    초대 메일이 도착해요

    메일의 수락 버튼을 눌러 조직에 참여해 주세요.

  2. 행사 당일

    Copilot으로 실습해요

    GitHub Codespaces, GitHub Copilot CLI, GitHub Copilot App, GitHub.com, GitHub Mobile App, VS Code 등에서 GitHub Copilot을 사용할 수 있습니다.

  3. 행사 약 3일 후

    조직과 자료가 삭제돼요

    필요한 코드는 행사 중에 개인 저장소로 옮겨 두세요.

꼭 알아 두세요

  • !

    개인(Individual) Copilot 구독이 있다면 조직 참여 시 취소되고 환불돼요. 행사용 새 GitHub 계정을 권장합니다.

  • !

    회사(Business/Enterprise) 라이선스는 유지돼요. 행사 중에는 Copilot 설정에서 Usage billed to를 MSFT/GH Hackathons로 바꾸고, 행사 후 원래대로 되돌려 주세요.

  • !

    기밀·민감 정보, 개인정보, 회사 소유 자료는 올리지 마세요. 작업물이 다른 참가자나 인터넷상 누구에게나 보일 수 있어요.

문의 사항은 본 메일에 회신해 주시면, 담당자를 통해 답변드리겠습니다.
