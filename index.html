필수 실습 · 첫 로그인, 암호 변경, MFA 등록

로그인 계정: 본인 UPN과 별도 경로로 받은 초기 암호. 첫 암호 변경·MFA 등록은 본인이 완료합니다. 아래 절차를 마친 뒤 리소스 생성 실습으로 넘어갑니다. 화면 표시 순서·허용 인증 방법은 조직 정책에 따라 다를 수 있습니다.

  1. 본인 발급 계정으로 로그인: 운영자가 승인한 교육망·기기에서 별도 브라우저 프로필이나 InPrivate 창으로 Azure Portal을 엽니다. 운영자에게 받은 본인 UPN 전체와 별도 경로로 받은 초기 암호를 입력합니다. 평소 쓰는 회사·개인 계정으로 대신 로그인하지 않습니다.
  2. 첫 암호 변경: 암호 업데이트 화면에서 현재 암호에는 초기 암호를, 새 암호·확인에는 조직의 암호 정책을 충족하는 본인 암호를 입력합니다. 이후 로그인에는 변경한 암호를 사용합니다. 변경 화면이 나오지 않거나 초기 암호가 거부되면 운영자에게 확인하고, 변경한 암호를 운영자에게 보내지 않습니다.
  3. 본인 MFA 등록: “추가 정보 필요 / More information required” 등의 안내에서 다음 / Next을 선택하고 조직이 허용한 인증 방법을 등록합니다. Microsoft Authenticator를 안내받았다면 본인 휴대폰에 앱 설치 → 앱에서 계정 추가 → 회사 또는 학교 계정 → QR 코드 스캔 → 본인 브라우저의 등록 QR 스캔 → 브라우저에서 다음 → 본인이 시작한 테스트 알림의 숫자 확인·승인 → 완료 순서로 진행합니다. 조직이 추가 인증 방법을 요구하면 화면 안내에 따라 함께 등록합니다. 필요하면 내 로그인 → 보안 정보에서 본인 계정·대상 테넌트를 확인한 뒤 등록 상태를 확인합니다.
  4. 재로그인·완료 확인: 로그아웃 후 새 브라우저 세션에서 변경한 암호와 본인 MFA로 다시 로그인합니다. Azure Portal 오른쪽 위의 UPN·디렉터리, 대상 구독과 본인 배정 RG를 확인합니다. 본인 RG가 보이고 접근할 수 있으면 01단계 · 계정·테넌트·배정 RG 확인으로 진행합니다.
인증은 본인이 직접 완료합니다. 운영자·다른 참가자의 휴대폰이나 인증수단을 등록하지 않습니다. 암호·MFA 코드·등록 QR을 공유하거나 캡처해 제출하지 않으며, 본인이 시작하지 않은 인증 요청은 승인하지 않습니다. 휴대폰이 없거나 등록·암호 변경이 차단되면 문제 대응표와 승인된 문의 경로로 지원을 요청합니다. MFA·조건부 액세스를 해제하거나 우회하지 않습니다.
영상은 이 필수 실습을 대신하지 않습니다. 로그인·암호 변경·MFA 등록 화면은 보안상 녹화에 포함하지 않았습니다. 아래 01단계 화면은 인증을 마친 상태에서 시작합니다.
